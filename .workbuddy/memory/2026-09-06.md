## DeepSeek API 接入邮件内容生成（约 16:40 完成）

### 改动
- 新增 `config/DeepSeekProperties`：`enabled/api-key/base-url(默认 https://api.deepseek.com)/model(默认 deepseek-chat)/timeout-seconds=30/max-tokens=1024/temperature=0.7`，全部支持环境变量覆盖。
- 新增 `mail/infrastructure/DeepSeekClient`：封装 DeepSeek Chat Completion（兼容 OpenAI 格式），system prompt 指示生成纯文本中文会议邮件，要求以 `{"subject","body"}` JSON 返回；解析时剔除 ```json 代码块包裹；失败/未配置返回 null。
- 改造 `TaskMailAutomationService.resolveContent`：无数据库模板时**优先调 DeepSeek**，未配置或调用失败降级到 `buildBody` 硬编码兜底；保留 `PENDING_REVIEW` 审核流程不变。
- 新增 `resolveSceneLabel(taskCode)`：把 taskCode 映射成中文场景描述（评审通知/注册缴费/参会指南等）喂给 DeepSeek。
- 提取 `buildVariables(conference, targetRole)` 复用变量构造。
- 改造 `refreshSystemDrafts`：**只刷新有数据库模板的草稿**，DeepSeek 生成的草稿首次创建后不再自动覆盖（避免每分钟重复调用浪费 token）。
- `application.yml` 新增 `deepseek:` 配置段。

### 链路
任务临近(7天窗口) → createPlanIfMissing 首次创建草稿 → resolveContent：数据库模板优先 → DeepSeek 次选 → 硬编码兜底 → PENDING_REVIEW → 组织者审核 → APPROVED 到点自动发送。
