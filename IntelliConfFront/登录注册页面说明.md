# IntelliConf 登录注册页面使用说明

## 🎉 已完成功能

### 1. 页面结构
- **登录/注册集成页面** (`/auth`)
  - 使用 Element Plus Tabs 实现登录和注册切换
  - 渐变背景 + 白色卡片居中布局
  - 响应式设计，支持手机和桌面端

- **仪表盘页面** (`/dashboard`)
  - 包含顶部导航栏（带退出登录按钮）
  - 嵌入原有的 ExecutionDashboard 组件

### 2. 表单功能

#### 登录表单
- **字段**：用户名、密码
- **校验规则**：
  - 用户名：必填
  - 密码：必填
- **功能**：
  - 支持回车提交
  - 提交时显示 loading 状态
  - 登录成功后自动跳转到 `/dashboard`
  - 将 token 保存到 localStorage

#### 注册表单
- **字段**：用户名、邮箱、密码、确认密码
- **校验规则**：
  - 用户名：必填，4-20位
  - 邮箱：必填，符合邮箱格式
  - 密码：必填，至少6位，必须包含数字和字母
  - 确认密码：必填，需与密码一致
- **功能**：
  - 支持回车提交
  - 提交时显示 loading 状态
  - 注册成功后自动切换到登录标签页

### 3. API 对接

#### 登录接口
```
POST /api/intelli-conf/v1/user/login
Request Body: { username, password }
```

#### 注册接口
```
POST /api/intelli-conf/v1/user
Request Body: { username, email, password }
```

### 4. 路由配置
```
/          → 重定向到 /auth
/auth      → 登录/注册页面
/dashboard → 仪表盘（需要登录）
```

## 📝 使用流程

1. **访问应用**
   - 打开浏览器访问 `http://localhost:5174/`
   - 自动跳转到登录页面

2. **注册账号**
   - 点击"注册"标签页
   - 填写用户名（4-20位）
   - 填写邮箱地址
   - 输入密码（至少6位，含数字和字母）
   - 确认密码
   - 点击"注册"按钮

3. **登录系统**
   - 在"登录"标签页输入用户名和密码
   - 点击"登录"按钮或按回车键
   - 登录成功后自动跳转到仪表盘

4. **退出登录**
   - 在仪表盘页面右上角点击"退出登录"按钮
   - 自动清除 token 并返回登录页面
